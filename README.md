# CA_Sahaayak

A web-based utility portal designed to simplify everyday operational tasks for Chartered Accountants through a clean, centralized workspace.

The platform provides quick access to essential calculators and professional tools, helping improve accuracy, reduce repetitive manual work, and streamline routine workflows.

---

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python

---

## Core Features (yet)
- Basic Calculator
- Advance Tax Calculator
- Capital Gains Calculator
---

## Project Purpose

This project is built as a scalable CA utility platform that centralizes frequently used professional tools into one interface.

The current version focuses on:

- clean dashboard-based navigation
- modular architecture
- reusable frontend components
- backend-driven tax calculations
- future extensibility for additional CA utilities

## Current Architecture

The application follows a simple frontend-backend separation allowing financial calculation logic to remain isolated and easy to maintain:

- Next.js handles UI, forms, navigation, and result rendering
- FastAPI handles calculation logic through Python functions
